PythonGPT

Teaching a small language model to write better Python, one measured experiment at a time.

TBDIn progress · Initial supervised model evaluated
Python · PyTorch · Transformers · TRL · Qwen2.5-Coder · Docker

A small model, a complete training loop.

I’m post-training Qwen2.5-Coder-0.5B from its base checkpoint to specialize in Python coding. The project connects dataset preparation, supervised fine-tuning, checkpoint saving and reloading, and execution-based evaluation.

The first supervised run used OpenCoder’s educational instruction data. With an initial checkpoint now evaluated, the focus is on improving the training examples and comparing recipes under the same evaluation setup.

Initial SFT results recorded November 11, 2026: pass@1 across 164 tasks, with one greedy answer per task. A same-protocol base-model comparison is still pending, so these scores establish a starting point rather than a measured training gain.

What’s in place

  • Supervised training and evaluation. A Python preparation and training workflow, saved-checkpoint inference, and a HumanEval / HumanEval+ runner separate answer generation from isolated correctness grading.
  • Teacher distillation in three stages. The program assigns skills, question forms, and difficulty; DeepSeek generates problems, solutions, and tests. A verification stage is designed to execute solutions in Docker, check signatures and docstring examples, and filter failed attempts.
  • A common data pipeline. Curation scripts bring several public coding datasets and distilled examples into one format, remove repeats, screen for benchmark overlap, and build model-ready training and validation splits.

Current stage. The initial SFT checkpoint has been evaluated. The newer distillation and curation tools have offline checks and small data-format trials; their full Docker workflow, dataset yield, and effect on model quality remain to be measured.

The next experiment

Run a bounded distillation pilot, inspect accepted examples, and build the next curated training set. Compare the resulting supervised model with the original base under a consistent protocol, then explore reinforcement learning with rewards from executable Python tests.

PythonGPT remains an active experiment. The final model, larger training results, and reinforcement-learning results are TBD.
